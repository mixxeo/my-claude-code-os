# 월간 회고 Orchestrator

오늘 날짜를 기준으로 이번 달의 월간 회고를 진행합니다.
**반드시 아래 단계를 순서대로 실행하세요. 각 단계는 이전 단계가 완료된 후 시작합니다.**

---

## PHASE 1: 컨텍스트 로딩

다음 두 가지를 동시에 실행하세요:

1. `.claude/context/user-profile.md` 파일을 읽어 사용자 컨텍스트를 파악한다.
2. `retrospectives/weekly/` 디렉토리에서 이번 달(YYYY-MM)에 해당하는 주간 회고 파일들을 모두 읽는다.
   - 파일명 패턴: `YYYY-MM-DD.md` 또는 `YYYY-WXX.md`
   - 파일이 없으면 "주간 회고 파일 없음"으로 처리하고 계속 진행한다.

PHASE 1이 완료되면 다음을 출력한다:

```
📋 [YYYY년 MM월 회고를 시작합니다]

✅ 컨텍스트 로딩 완료
✅ 주간 회고 파일 {N}개 발견: {파일명 목록}

이번 달 주간 회고 요약:
{주간 회고 내용을 2-3줄로 압축 요약. 파일이 없으면 "주간 회고 없음" 표시}
```

---

## PHASE 2: 인터뷰 — WORK

다음 메시지를 출력하고 사용자의 답변을 기다린다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💼 WORK 인터뷰
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이번 달 업무에 대해 답해주세요.

1. 이번 달 처리한 주요 Jira 티켓이나 업무를 나열해주세요.
   (예: "로그인 버그 수정, 결제 API 개선, 신규 기능 A 설계")

2. 이번 달 가장 뿌듯했던 업무 성과는 무엇인가요?

3. 업무적으로 어렵거나 아쉬웠던 점이 있었나요?

자유롭게 답변해주세요. (건너뛰려면 "없음" 또는 "패스" 입력)
```

사용자 답변을 받으면 `work_data` 변수에 저장하고 PHASE 3으로 진행한다.

---

## PHASE 3: 인터뷰 — HEALTH

다음 메시지를 출력하고 사용자의 답변을 기다린다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🏃 HEALTH 인터뷰
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이번 달 건강/운동에 대해 답해주세요.

1. 이번 달 운동 횟수와 주요 활동을 알려주세요.
   (예: "헬스 8회, 러닝 3회, 총 11회")

2. user-profile의 운동 목표 대비 달성도는 어떤가요?

3. 건강 관련 특이사항이 있었나요?
   (부상, 체중 변화, 컨디션 이슈 등)

자유롭게 답변해주세요. (건너뛰려면 "없음" 또는 "패스" 입력)
```

사용자 답변을 받으면 `health_data` 변수에 저장하고 PHASE 4로 진행한다.

---

## PHASE 4: 인터뷰 — FINANCIAL

다음 메시지를 출력하고 사용자의 답변을 기다린다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💰 FINANCIAL 인터뷰
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이번 달 수입/지출에 대해 답해주세요.

1. 이번 달 총 지출은 얼마였나요? 주요 소비 항목은?
   (예: "총 230만원 / 외식 40만원, 쇼핑 30만원, 여행 50만원")

2. 이번 달 저축/투자 실행 내역을 알려주세요.
   (예: "ETF 50만원 매수, 예금 50만원 → 목표 대비 100% 달성")

3. 투자 결과나 자산 변동이 있었나요?
   (예: "포트폴리오 +2.3%, 달러 환차손 발생")

자유롭게 답변해주세요. (건너뛰려면 "없음" 또는 "패스" 입력)
```

사용자 답변을 받으면 `financial_data` 변수에 저장하고 PHASE 5로 진행한다.

---

## PHASE 5: 회고 종합 인터뷰

다음 메시지를 출력하고 사용자의 답변을 기다린다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🪞 이번 달 회고
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

마지막으로 이번 달 전반에 대해 답해주세요.

1. 이번 달 가장 좋았던 점은 무엇인가요?
   (업무/건강/생활 모두 포함)

2. 아쉬웠거나 개선하고 싶은 점은 무엇인가요?

3. 다음 달에 꼭 실천하고 싶은 Action Item이 있다면?
   (구체적일수록 좋습니다)

자유롭게 답변해주세요.
```

사용자 답변을 받으면 `retro_data` 변수에 저장하고 PHASE 6으로 진행한다.

---

## PHASE 6: 회고 문서 생성

지금까지 수집한 모든 데이터(user-profile, 주간회고, work_data, health_data, financial_data, retro_data)를 종합하여 월간 회고 문서를 작성한다.

### 작성 원칙

- **성장 지향적**: 후회보다 다음 달에 더 잘할 수 있는 방향으로 서술한다.
- **삶의 목표 연결**: user-profile의 "삶의 목표"와 연결지어 이번 달의 의미를 짚는다.
- **구체적 Action Item**: 막연한 다짐이 아닌 실행 가능한 항목으로 작성한다.

### 출력 파일 경로

`retrospectives/monthly/YYYY-MM.md` (오늘 날짜 기준 연월)

### 문서 형식

```markdown
# YYYY년 MM월 월간 회고

> {이번 달을 한 문장으로 표현}

---

## 지난 달 목표 돌아보기

{이전 월간 회고 파일이 있으면 "다음 달 목표" 항목을 읽어와서 표시. 없으면 "첫 번째 월간 회고입니다." 표시}

---

## 📋 주간 회고 요약

{주간 회고 파일 내용을 바탕으로 이번 달의 흐름을 2-3개 bullet로 요약}

---

## 💼 WORK

### 주요 업무

{work_data 기반으로 Jira 티켓/업무 목록 정리}

### 이달의 성과

{뿌듯했던 성과를 1-2줄로}

### 아쉬운 점

{업무적 아쉬움}

---

## 🏃 HEALTH

### 운동 기록

{운동 횟수, 종류 정리}

### 목표 달성도

{user-profile 목표 대비 이번 달 달성도}

### 특이사항

{부상, 컨디션 이슈 등. 없으면 "없음"}

---

## 💰 FINANCIAL

### 이달 지출 현황

{총 지출액, 주요 카테고리별 지출}

### 저축/투자 실행

{실행 내역과 목표 대비 달성도}

### 투자 결과

{포트폴리오 변동, 특이사항}

---

## 🪞 이번 달 회고

### 좋았던 점

{긍정적인 것들}

### 아쉬웠던 점

{개선이 필요한 것들. 비판보다 배움의 관점으로}

---

## 🎯 다음 달 Action Items

- [ ] {구체적 액션 1}
- [ ] {구체적 액션 2}
- [ ] {구체적 액션 3}

---

## 🌟 다음 달 목표

> {다음 달을 한 문장으로 표현한 목표}

---

_회고 작성일: YYYY-MM-DD_
```

문서 생성이 완료되면 다음을 출력한다:

```
✅ 월간 회고가 완성되었습니다!
📄 저장 위치: retrospectives/monthly/YYYY-MM.md

{삶의 목표와 연결된 따뜻한 마무리 코멘트 1-2줄}
```
