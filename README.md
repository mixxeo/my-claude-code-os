# My-Claude-Code-OS

### OS list

- 기술 블로그를 작성하는 OS
- 회사에서 개발을 잘 하는 OS
- 1달 단위의 월간 회고를 하는 OS
- 하루동안 회사업무 한 내용을 회고하는 OS
- 불분명한 요구사항을 명확한 시나리오로 도출하는 OS
- 회사와 팀에 흩어져있는 지식과 노하우를 모으고 재사용하는 리소스를 만드는 OS
- spec driven development OS

### 1. 내 업무의 중심 워크플로우

- 매주 작성한 주간 회고를 돌아본다.
- 월 초에 작성했던 할일 목록을 점검한다. (은행 업무, 병원, 구매할 것, 공부할 것 등)
- WORK 측면: 회사에서 한달 동안 처리한 Jira Ticket을 살펴본다.
- HEALTH 측면: 한달 간 운동 기록을 확인한다.
- FINANTIAL 측면: 한달 간 수입과 지출을 점검한다.
  - 특히, 어느 쪽에서 소비를 많이했는지 확인
  - 투자 결과 확인
- 이번 달의 좋았던 점, 아쉬웠던 점, 다음달의 Action Item을 도출한다.
- 다음 달의 목표를 한 문장으로 정해본다.

### 2. OS에 꼭 포함되어야 하는 핵심 철학/관점

- 한 달을 돌아보고 후회하기보다, 다음달에 더 성장할 수 있는 방향으로 회고를 한다.
- 궁극적인 내 삶의 목표를 위해 다가가는 방향으로 한달을 보냈는지 회고를 한다.

### 3. OS가 일을 잘 하기위해 필요한 컨텍스트

- 나의 직업적 정보
- 커리어적으로 내가 앞으로 나아가고싶은 방향성
- 나의 건강 정보
  - 질병
  - 목표(다이어트, 근성장, 운동능력 등)
- 나의 경제적 상황
  - 월급
  - 고정지출
  - 투자 포트폴리오
- 내 삶의 목표
